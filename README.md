# myAgentLab - Multi-Agent and Agentic LLM Papers
 
A curated collection of LLM-based multi-agent research. Reflection, reasoning, planning, verification, and decomposition are treated as foundations on which multi-agent roles, communication, and orchestration are built. Papers are grouped by their primary contribution; links point to open arXiv abstract pages.

## Self-Improving Agents and Harness Evolution

These works improve agents by updating skills, prompts, policies, code, or system structure from experience and evaluation. Harness research is included because the harness controls prompts, state, tools, and execution. *Harness Handbook* improves behavior localization and modification planning; it supports future harness self-evolution rather than performing autonomous self-improvement by itself.
